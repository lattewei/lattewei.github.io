Onchain data infrastructure

I am building a Go API that collects, processes, and exposes market and trading data from the chain.

Solana first. The goal is to pull onchain data, shape it, and serve it as fast as possible, especially for trading engines.

Next: host my own nodes, and keep the pipeline clean end to end.

This project is private. It is not open source.
